# GA4 クリック計測の修正と追加（2026-11-24）

技術SEO監査（`docs/audit/technical-2026-11-24.md` §5）の対応。11/10 以降の `internal_nav` と `amazon_link_click` は、`window.gtag` が未定義のため **一度も送信されていなかった**。修正後（本変更のデプロイ日）を、導線施策の比較の新しい起点にする。11/10〜デプロイ前のイベントは復元できない。

## 送信するイベント

| イベント | 条件 | パラメータ | 備考 |
| --- | --- | --- | --- |
| `internal_nav` | `a[data-nav]` のクリック | `nav`、`dest_path` | `nav` は `{場所}-{行き先}` |
| `amazon_link_click` | `a[rel~="sponsored"]` のクリック | `link_url`、`item_name` | `item_name` は `data-item`、なければカード内の商品名 |
| `video_play_click` | `a[data-yt-embed]`（クリックで再生） | `video_title` | 修飾キー付きは数えない |

共通: `transport_type: 'beacon'`。左クリックに加え、中ボタン（`auxclick`）も数える（YouTube を除く）。

## `nav` の値

| 場所 | 値 |
| --- | --- |
| ヘッダー（PC）／ロゴ | `header-{basics,gear,skills,glossary,start}`／`header-home` |
| ヘッダー（スマホのメニュー） | `header-menu-{basics,gear,skills,glossary,start}` |
| フッター | `footer-{basics,gear,skills,glossary,start}`、`footer-about`、`footer-privacy` |
| トップ | `home-card-{basics,gear,skills,glossary,start}`、`home-hero-what-is-ultimate` |
| 各一覧のカード | `hub-{basics,gear,skills,start}-{記事のslug}` |
| 用語集の一覧 → 個別 | `glossary-index-{用語}`（見出し）、`glossary-index-more-{用語}`（「…を読む」） |
| 用語の個別ページ → 一覧 | `glossary-term-index` |
| 次の一歩（既存） | `nextstep-*`、`nextstep-glossary-*` |

## 運営者の作業（GA4 管理画面）

1. **カスタムディメンションの登録**（管理 → カスタム定義 → カスタム ディメンション。スコープは「イベント」）:
   `nav`、`dest_path`、`item_name`、`link_url`、`video_title`。登録後に集計されたデータだけがレポートで使える（過去分はさかのぼらない）。
2. **DebugView での確認**:
   1. Chrome で Tag Assistant（tagassistant.google.com）に公開URL を接続するか、拡張機能「Google Analytics Debugger」を有効にする（どちらも `debug_mode` が付き、DebugView に出る）。
   2. GA4 の 管理 → DebugView を開く。
   3. サイトで、ヘッダーのリンク、フッターのリンク、一覧のカード、用語集の一覧のリンク、Amazon のリンク、動画の再生ボタンを順にクリックする。
   4. DebugView に `internal_nav`／`amazon_link_click`／`video_play_click` が出て、パラメータ（`nav`、`item_name` など）が入っていることを確認する。
3. GA4 の拡張計測（外部リンクのクリック）が有効だと、Amazon リンクは `click`（`outbound=true`）とも二重に記録される。`amazon_link_click` は商品名つきの集計用として使い、拡張計測の `click` とは分けて見る。

## 比較の準備（ベースライン）

- 用語集一覧を簡素化したので、デプロイ前に Search Console で `/glossary/` と 12 用語の表示回数・クリック・平均掲載順位を控え、約 4 週間後に比較する。URL 検査で「Google が選択したカノニカル」も確認する（`/glossary/` と出ていれば重複が原因の裏づけになる）。
- 一覧 → 個別のクリックは `glossary-index-*` で見る。
