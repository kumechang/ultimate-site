## 1. IndexNow

ページの追加・更新をBingなどの検索エンジンへ通知する仕組み。

- 鍵ファイル: `public/eb415e53c557e6300b6a0c12ce21331f.txt`（公開URL: `https://ultimate-navi.com/eb415e53c557e6300b6a0c12ce21331f.txt`、中身は鍵そのもの）
  - 鍵は公開される前提のもの（秘密情報ではない）。
- 送信スクリプト: `scripts/seo/indexnow.py`
  - `--dry-run`: 送信先とURL数だけ確認
  - 引数なし: サイトマップ（`sitemap-0.xml`）の全URLを `https://api.indexnow.org/indexnow` へ送信
  - `--url <URL>`: 指定したURLだけ送信（繰り返し指定可）
  - 送信前に鍵ファイルが公開されていることを確認し、見えない場合は送信しない。
- 確認済み: ビルドで鍵ファイルが `dist/` に出力される／`--dry-run` でサイトマップから38URLを取得できる。

### 運用
1. 記事の追加・大きな更新のあと、デプロイが終わってから `python3 scripts/seo/indexnow.py --url <更新したURL>` を実行する。
2. 初回（鍵ファイルのデプロイ後）は、全URLを1回送信する。
3. 自動化したい場合は、Cloudflare の「Crawler Hints」（Caching > Configuration）をオンにすると、IndexNowによる通知をCloudflare側が行う。この場合、上のスクリプトは補助になる。

### 注意
- IndexNowは、Bing・Yandex・Naver・Seznam などが参加している。**Googleは参加していない**ため、Googleへの通知は従来どおりSearch Consoleのインデックス登録リクエストで行う。
- 送信は「更新の通知」であり、インデックスや順位を保証するものではない。

## 2. メタディスクリプションの拡充

Bingが短いと指摘したページのうち、特に短かった3ページ（39〜41字）を、ページの内容に沿って書き直した。titleは変更していない（10月中旬の変更の効果測定中のため、11月上旬まで触らない）。

## 3. 運営者の作業（コードでは対応できないもの）

### 高品質なドメインからのインバウンドリンク
- 他サイトからのリンクは、コードでは増やせない。次のような自然な紹介の機会を作る。
  - 大学サークル・団体・個人ブログなどに、役立つ記事（ルール、用語集、スーパープレー集など）を紹介してもらう。
  - 公式団体や自治体のリンク集に、掲載してもらえるか相談する。
- 次のことは避ける: リンクの売買、相互リンクの大量依頼、掲示板・SNSへの機械的な投稿（検索エンジンの規約違反になりうる）。

### マージ後にやること
1. デプロイ後に `https://ultimate-navi.com/eb415e53c557e6300b6a0c12ce21331f.txt` が表示されることを確認する。
2. `python3 scripts/seo/indexnow.py` を実行して、全URLを送信する（初回）。
3. Bing Webmaster Tools の「IndexNow」の画面で、送信が反映されたか見る（反映まで時間がかかることがある）。
4. 1〜2週間後に、SEO Recommendations の指摘が減ったか確認する。

## 4. 関連メモ
- 今回の指摘は「ページ数」が少ない（メタディスクリプションは1ページ）ため、緊急性は低い。IndexNowの導入が最も効果の見込みが大きい。
