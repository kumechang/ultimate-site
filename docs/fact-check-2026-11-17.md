# 公式ルール・日本の大会情報との突き合わせ（2026-11-17）

運営者が競技未経験のため、サイトの記述を、WFDF Rules of Ultimate 2025-2028（本則・Basic版・Official Annotations・Summary of Changes）と、JFDAの公式情報に突き合わせた。調査は3領域（用語集／基本記事・スロー／始め方・大会）。

## 見つかった主な誤りと対応
| ページ | 誤り | 対応 |
| --- | --- | --- |
| 基本ルール／プル | 得点された側がプルを投げる | 得点した側が守備側としてプルを投げる（本則 4.5.3, 7.1） |
| 基本ルール | ハーフタイムは先取点数の半分／キャップ時は残り得点を調整 | 先に8点でハーフ（7分）／100分（前半55分）のキャップで、リード側+1点が新しい目標（2021-2024年版の大会規定） |
| ピック | 意図的な妨害／必ず反則 | 意図は問わない。ディフェンスがコールするバイオレーション（18.3） |
| ピボット／トラベリング | 歩数の規定はない | 「○歩」の一律制限はないが、走りながらのキャッチ後は追加の接地2回までの例外（18.2.1.1）。トラベル指摘時の扱いを訂正 |
| ストールカウント | 10まで数えた時点／約1秒間隔 | 「10」と言い始める前／少なくとも1秒間隔（9.1, 13.2.2） |
| ターンオーバー | 手渡し／ドロップト・プル | 意図的な手渡し／触れたのに保持できなかった場合 |
| カップ | ロングスローを誘発する | 前進するパスを防ぎ、横・後ろへのパスに誘導する |
| ミックス | 数少ない競技／大学サークルの多くは混合／性別を問わず | 根拠のない表現を削除。男女比4:3の部門。大学の主要大会はオープン・ウィメンの2部門で、ミックスは別大会 |
| 沿革 | 1984年にWFDF発足／日本へは1980年代前半 | 1984年に設立が決まり1985年に発足／伝来時期は確認できないため削除 |
| 年間スケジュール | 12〜3月はオフシーズン／6〜8月に大学の大会 | 冬〜春にも大会がある／全日本大学の予選は8月末〜 |
| 費用 | JFDA会員費の記載なし | A会員 年6,000円（18歳未満3,000円）＋入会金1,000円などを追記 |
| スロー | バックハンドは手首を返さず離す | 手首をスナップして回転をかける（経験者の確認を推奨） |
