# 外部画像のクレジット管理

外部の写真を使うときは、記事のfrontmatterに `heroImageCredit`（作者・ライセンス・出典URL）を書く。画像の下に、クレジットが自動で表示される。
画像は、ファイルページから取得して、サイトにコピーして使う（直リンクはしない）。

## 運用
- ライセンス・作者・年代（未成年が主役でないか）を、ファイルページと画像で確認してから使う。
- CC BY-SA の画像は、加工したものも同じライセンスで公開する扱いになる（記事の画像にそう明記されている）。
- 写っている人から削除の依頼があれば、速やかに画像を外す（連絡先は /privacy/）。
