## 結論：サッカー用のスパイクを、練習場所に合わせて選ぶ

アルティメットでは、サッカー用（またはラグビー用）のスパイクを使う選手が多くいます。筆者の調べた範囲では、日本で入手しやすい国内メーカーのアルティメット専用モデルは確認できませんでした（海外にはアルティメット専用をうたうブランドもあります）。

選び方の基準は、モデルの優劣よりも**「普段どこで練習するか」**です。

| 主な練習場所 | 選ぶタイプの目安 |
| --- | --- |
| 土のグラウンド（大学・公営グラウンドなど） | HG、またはTF |
| 人工芝のコート | TF、AG（メーカーによって対応が異なる） |
| 天然芝 | FG |
| 体育館 | 室内用シューズ（スパイクは使えないことが多い） |

練習場所が複数ある場合は、いちばん多く使う場所に合わせるのが基本です。迷ったら、所属チームの先輩や主催者に「このグラウンドは何タイプが多いか」を聞くのが確実です。

## スタッドタイプの違い（HG・FG・AG・TF・IN）

サッカー用スパイクの底（スタッド）は、対応する地面ごとに種類が分かれています。表記はメーカーによって多少異なるため、**購入前に商品ページの「対応グラウンド」を確認**してください。

| 表記 | 一般的な意味 | 主な対応地面 |
| --- | --- | --- |
| HG（ハードグラウンド） | 硬い土向け。スタッドの数が多めで踏ん張りやすい | 土のグラウンド |
| FG（ファームグラウンド） | 天然芝向けの成形スタッド | 天然芝 |
| AG | 人工芝向け。短めのスタッド | 人工芝 |
| TF（ターフ） | 細かい突起。アシックスは「土・人工芝」、ナイキは「芝と一部の硬い地面」と説明 | 土・人工芝など（メーカーにより幅がある） |
| SG（ソフトグラウンド） | ぬかるんだ・柔らかい芝向けで、長めのスタッド | 雨で緩んだ天然芝 |
| IN / IC | 体育館・コンクリートなど屋内向け | 体育館（フロア） |

TFやAGはメーカーごとに想定する地面が異なります。「TFだから人工芝も土もすべて対応」と決めつけず、商品ページの説明で確認しましょう。

## 金属スタッドの注意点（WFDFの規定と会場ルール）

安全面では、金属スタッドが特に重要です。

- WFDF競技規則（2025-2028）の3.4は、自分や相手を傷つけるおそれのある衣類・用具の着用を禁じています。
- WFDF公式解釈集（Official Annotations）には、「完全金属製のスタッド、長いスタッド、鋭い縁のスタッドは靴に使えない」という趣旨の記載があります。
- 取り替え式のSGなどには、金属スタッドを採用するモデルがあります。その場合、アルティメットでは使えない可能性があります（モデルごとに商品ページで確認してください）。
- 自治体の運動施設には、金属スパイクの使用を禁止しているところがあります（例：世田谷区のJ&Sフィールド、岐阜市の島西運動場の人工芝）。

これらはあくまで一般的な目安です。**練習・試合の会場ごとに、施設や主催者のルールを事前に確認**してください。JFDA（日本フライングディスク協会）主催大会の共通注意事項にも、スパイク禁止エリアが指定された会場では掲示に従うよう書かれています。

> 一部に金属を含むスタッドが可かどうかは、公式には定義されていません。判断に迷う場合は、大会や会場の運営に確認してください。

## サッカー用とラグビー用の違い

ラグビー用スパイクも使われていますが、ラグビー用は競技の特性に合わせて設計されています。

- World Rugbyのスタッド規格はラグビーの試合のための規則で、**アルティメットには適用されません**。「ラグビー用だから使える」とは言えません。
- ラグビー用には、取り替え式で長めのスタッドを採用するモデルがあるとされます。長いスタッドや金属スタッドは、アルティメットでは認められない場合があるため、スタッドの素材と長さを確認してください。

ラグビー経験者の方は、[アルティメットとラグビーの違い](/basics/vs-rugby/)もあわせてご覧ください。

## 選ぶときのチェックポイント

1. **練習場所の地面**：土・天然芝・人工芝・体育館のどれが多いか
2. **スタッドの素材**：金属でなく、樹脂（プラスチック・ゴム）製か
3. **サイズ**：足の長さと幅に合っているか
4. **会場ルール**：スパイクの使用や金属スタッドに制限がないか

### サイズ選びの目安

サイズの合わないスパイクは、足への負担や不快感の原因になります。メーカーのガイドを参考に、次の点に気をつけましょう。

- 午後に試着する（ランニングシューズ向けの目安として、アシックスが案内）
- つま先に1cm前後の余裕を持たせる（同上）
- 両足を試し、靴ひもを結んで確認する
- 足の長さだけでなく、幅や形も選ぶ基準にする（同じサイズでもモデルによって形が異なります）

スパイクは競技専用の用品ではなく、足首や膝のケガを完全に防ぐものではありません。練習前のウォームアップも行いましょう。

## よくある質問

### アルティメット専用のスパイクはありますか？

筆者の調べた範囲では、日本で入手しやすい国内メーカーのアルティメット専用モデルは確認できませんでした。海外には専用設計をうたうブランドもありますが、日本国内での入手性は確認できていません。多くの選手は、サッカー用などのスパイクを使っています。

### 金属スタッドのスパイクは使えますか？

WFDFの公式解釈集では、完全金属製のスタッドなどは靴に使えないとされています。大会や会場によってルールも異なるため、事前に確認してください。

### 初心者はスパイクを買う必要がありますか？

必要かどうかは練習場所や主催者によって異なります。参加前に、主催者や所属チームに確認すると安心です。必要な道具の優先順位は、[始めるのに必要な道具](/start/what-to-buy/)にまとめています。

### どこで練習するかまだ決まっていません

まず練習場所を確認してから選ぶのが無駄がありません。[体験できる場所の探し方](/start/where-to-play/)も参考にしてください。

ギア全体の予算は[ギア一式の費用目安](/start/cost/)を、足元の消耗を和らげる[スポーツソックスなどのウェア](/gear/apparel/)もあわせてご覧ください。
